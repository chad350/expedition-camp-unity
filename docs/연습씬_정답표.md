# 연습 씬 정답표

## 1. 씬 위치와 공통 사항

| 항목 | 내용 |
|---|---|
| 씬 폴더 | `UnityProject/Assets/Scenes/Practice/` |
| 연습용 리소스 | 프리팹 `Assets/Practice/Prefabs/`<br>재질 `Assets/Practice/Materials/`<br>스크립트 `Assets/Practice/Scripts/`<br>소품 이미지 `Assets/Sprites/Props/` |
| 게임과 공유 여부 | 연습 씬은 게임 프리팹을 사용하지 않습니다.<br>연습 중 Apply를 눌러도 게임 쪽 프리팹은 바뀌지 않습니다.<br>P6 의 `GameConfig.asset` 과 `shop.csv` 는 게임과 같은 파일입니다. |
| 빌드 씬 목록 | 연습 씬 6개는 빌드 씬 목록에 없습니다.<br>Project 창에서 씬 파일을 더블클릭해서 엽니다. |
| 화면 저장 위치 | `docs/screenshots/phaseA/scene_P*_1920x1080.png` |

| 실습 번호 | 문제 위치 (Hierarchy 경로) | 컴포넌트 | 칸 이름 | 원래 값 | 정상 값 | 증상 |
|---|---|---|---|---|---|---|
| 3-1 | Canvas > Btn_Sound | Sound Button | Audio Source | None | Speaker (Audio Source) | 버튼을 누르면 Console 에 빨간 에러가 나옵니다.<br>에디터 Console 표시는 `UnassignedReferenceException: The variable audioSource of SoundButton has not been assigned.` 입니다.<br>에러 위치는 `SoundButton.cs:11` 입니다.<br>빌드에서는 같은 원인이 NullReferenceException 으로 표시됩니다. |
| 3-2 | Canvas > Btn_Result | Button | 컴포넌트 체크박스 | 꺼짐 | 켜짐 | 버튼을 눌러도 결과 창(Panel_Result)이 열리지 않고 Console 에 아무것도 나오지 않습니다.<br>Missing Script 는 없습니다. |
| 따라 하기 | Windmill | Rotator | Rotate Speed | 30 | 30 | Play 중 0.5초에 약 15도 회전합니다.<br>300 으로 바꾸면 빨라지고 Play 를 끝내면 30 으로 돌아옵니다. |
| 처치 재현 | Monster_Target | Practice Health | Hp | 100 | 100 | Btn_Damage 를 누르면 10씩 줄어듭니다.<br>Play 중 Hp 를 1 로 바꾸고 Btn_Damage 를 누르면 커지면서 투명해지는 처치 연출 뒤 사라집니다. |

- 정상 동작하는 버튼은 `Btn_Damage` (체력 감소) 입니다.
- 계획서와 교안은 "None 칸은 NullReferenceException" 으로 설명합니다.
Unity 6000.3 에디터는 인스펙터 칸이 None 인 경우 UnassignedReferenceException 을 표시하므로, 교안에 두 이름을 함께 적는 것을 권장합니다.
