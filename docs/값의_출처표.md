# 값의 출처표

## 1. 값 이름과 출처

출처는 4가지로 나뉩니다.
같은 값은 2가지 출처에 동시에 두지 않았습니다.

## 3. 프리팹 규칙 (3단계 프리팹 규칙 검사 기준)

| 프리팹 | 파일 | 루트 Tag | 루트 Layer | 자식 Layer | Collider | Is Trigger | Rigidbody |
|---|---|---|---|---|---|---|---|
| Player | `Assets/Prefabs/Player.prefab` | Player | Player | Player | Character Controller | 해당 없음 | 없음 |
| Monster_Base | `Assets/Prefabs/Monster_Base.prefab` | Monster | Monster | Monster | Character Controller | 해당 없음 | 없음 |
| Monster_Crab · Monster_Rabbit · Monster_Bat · Monster_Golem · Monster_Wolf | `Assets/Resources/Monsters/` | Monster | Monster | Monster | Character Controller | 해당 없음 | 없음 |
| DropItem | `Assets/Prefabs/DropItem.prefab` | DropItem | DropItem | DropItem | Sphere Collider | 켜짐 | Is Kinematic 켜짐 · Use Gravity 꺼짐 |
| SpawnPoint | `Assets/Prefabs/SpawnPoint.prefab` | Untagged | Default | 없음 | 없음 | 해당 없음 | 없음 |
| NPC_Shop · NPC_Dex · NPC_Board | `Assets/Prefabs/NPC/` | Untagged | Default | Default | Box Collider 2D | 꺼짐 | 없음 |

- 메인 카메라 Culling Mask(Field_01 · Field_02)는 Default · UI · Monster · Player · DropItem · Ground · Obstacle 7가지입니다.
Hidden Layer는 Culling Mask에 넣지 않았습니다.
- 플레이어 자동 공격은 Tag가 Monster인 오브젝트만 대상으로 찾습니다.
- 바닥(Ground 오브젝트)은 Ground Layer, 바위 · 나무 기둥 · 동굴 벽 · 경계 벽은 Obstacle Layer입니다.

## 4. GameConfig 기준 값 (3단계 설정 값 검사 기준)

| 칸 이름 (asset 직렬화 이름) | 기준 값 |
|---|---|
| Time Scale (`timeScale`) | 1 |
| Camera Distance (`cameraDistance`) | 20 |
| Camera Pitch (`cameraPitch`) | 50 |
| Camera Yaw (`cameraYaw`) | 45 |
| Camera Look Height (`cameraLookHeight`) | 1 |
| Drop Item Lifetime (`dropItemLifetime`) | 30 |
| Wave Interval (`waveInterval`) | 1.5 |
| Drop Magnet Speed (`dropMagnetSpeed`) | 12 |

QAConfig 기준 값은 Random Seed(`randomSeed`) 0, Show Debug On Start(`showDebugOnStart`) 0 입니다.
