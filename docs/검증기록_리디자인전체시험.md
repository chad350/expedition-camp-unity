## 4. 재구성안

리디자인의 모습은 유지하고, 실습이 쓰는 구조(Variant · 로비 2D 정렬 · 고유 이름)는 되살리는 방향입니다.

| 묶음 | 재구성 | 되살아나는 실습 |
|---|---|---|
| 몬스터 3D 모델 | Monster_Base 의 Visual 에 `MonsterModel` 컴포넌트를 둡니다.<br>`Shape` (여우형 · 게 · 박쥐 · 골렘) 와 `Body Material` 칸을 Inspector 에 노출하고, 값에 맞는 3D 파츠를 표시합니다.<br>몬스터 5종은 Variant 로 유지하고 Shape · Body Material · Move Speed · Prefab Key 를 오버라이드합니다. | STEP 5 굵은 글씨 확인<br>STEP 6 새 Variant 실습 (Sprite 대신 Shape · Body Material 을 고릅니다)<br>break/05 |
| 체력바 높이 | Monster_Base 값을 2.15 로 두고 골렘 Variant 만 2.65 로 오버라이드합니다. | 확인 6번 (원본 변경이 4종에 전달)<br>골렘은 오버라이드 예시로 씁니다. |
| 몬스터 그림 | `mon_*.png` 는 도감 · 결과 창 아이콘으로 계속 씁니다. | 확인 4번 (Texture Type Sprite) |
| 로비 | 왼쪽 소개 패널 · 출정 버튼 · 상단 바는 유지합니다.<br>큰 여우 그림 대신 월드의 `Background` (Order 0) 와 NPC 3명 (Order 5 · 이름 6) 을 오른쪽 영역에 다시 둡니다.<br>NPC 클릭으로 팝업이 열리고, 출정 버튼은 출정 게시판 NPC 와 같은 팝업을 엽니다. | STEP 1 · 2 · 3 시연<br>확인 13번<br>break/01 · 09 |
| UI 색 | 리디자인 `Style` 대신 main 의 `UiTheme` 를 씁니다.<br>패널 Ink · 버튼 Panel 대비와 팝업 배경 그림, 결과 창 구성이 그대로 남습니다. | 결과 창 · 팝업 모습 |
| 환경 장식 | `Bridge_Post_L1` 처럼 번호를 붙인 고유 이름으로 만들고 `Art_Details` 아래에 묶습니다.<br>자갈은 `Pebble.mat` 을 따로 씁니다.<br>길 재질은 `Trail_Forest` · `Trail_Cave` 로 나눕니다. | break/16 이 정답표대로 바위만 바뀜<br>오브젝트 이름 규칙 설명 |
| 조명 · Volume · 타격 효과 · 카메라 | 그대로 가져옵니다. | 영향 없음 |
| QA 검사 규칙 | 허용 GUID 에 URP Volume 효과 · 파티클 셰이더를 넣고, 재질 셰이더 규칙에 파티클 셰이더를 더합니다.<br>수강생 `qa/rules` 와 강사용 `qa_complete/rules` 를 함께 고칩니다. | 3단계 검사 |
