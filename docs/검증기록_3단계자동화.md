## 3. 실행 중 찾아서 고친 문제

| 문제 | 원인 | 조치 |
|---|---|---|
| main 스모크가 8개 중 6개 실패 | 이전에 실행한 게임이 꺼지지 않고 7700 포트를 쓰고 있어서, 테스트가 새 빌드가 아닌 이전 게임(이미 필드에 있는 상태)에 연결했습니다. | `conftest.py` 가 게임을 실행하기 전에 포트가 비어 있는지 확인하고, 사용 중이면 이유를 적고 실패합니다.<br>고친 뒤 main 스모크 8개가 통과합니다. |

| Jenkins 에서 break 브랜치 테스트 결과에 이전 빌드의 통과 결과가 섞임 | 작업 폴더의 `reports/junit_*.xml` 이 빌드 사이에 남았습니다. | Jenkinsfile 0단계에서 `reports` 폴더를 비웁니다. |
