## 3. 실행 중 찾아서 고친 문제

| 문제 | 원인 | 조치 |
|---|---|---|
| main 스모크가 8개 중 6개 실패 | 이전에 실행한 게임이 꺼지지 않고 7700 포트를 쓰고 있어서, 테스트가 새 빌드가 아닌 이전 게임(이미 필드에 있는 상태)에 연결했습니다. | `conftest.py` 가 게임을 실행하기 전에 포트가 비어 있는지 확인하고, 사용 중이면 이유를 적고 실패합니다.<br>고친 뒤 main 스모크 8개가 통과합니다. |
| 파이썬에서 실행한 Unity 가 "Scripts have compiler errors" 로 멈춤 | 한글이 들어간 경로의 파이썬을 실행하면 환경 변수 `_` 에 깨진 글자가 들어가고, Unity 빌드 도구가 이 값을 읽다가 멈춥니다(`Illegal byte sequence`). | `unity_runner.py` 의 `clean_environment()` 가 `_` 와 UTF-8 이 아닌 값을 빼고 Unity 를 실행합니다. |
| Jenkins 에서 break 브랜치 테스트 결과에 이전 빌드의 통과 결과가 섞임 | 작업 폴더의 `reports/junit_*.xml` 이 빌드 사이에 남았습니다. | Jenkinsfile 0단계에서 `reports` 폴더를 비웁니다. |
| 1단계에서 변환 도구를 먼저 실행하면 break/14 를 찾지 못함 | 변환 결과가 잘못 저장된 CSV 를 덮어씁니다. | `tools/export_tables.py --out-dir` 로 임시 폴더에 변환해서 비교합니다. |
