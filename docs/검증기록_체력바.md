# 검증기록 · 체력바 줄어듦 수정

## 1. 문제

| 항목 | 내용 |
|---|---|
| 증상 | 플레이어 HP 300 / 1000, 게 HP 180 / 450 인데 두 체력바가 모두 가득 찬 길이로 그려집니다. |
| 원인 | Image Type 이 Filled 인 이미지에 Source Image 가 비어 있으면 Unity 가 Fill Amount 를 적용하지 않습니다. |
| 해당 이미지 | `Monster_Base.prefab` 의 `HPFill`<br>`Field_01.unity` · `Field_02.unity` 의 `Img_PlayerHpFill` |
| 참고 | `/Users/chad/Codex/EliceQA/expedition-camp-unity-redesign` 의 `SolidBar` 처리 |

## 2. 수정 내용

| 파일 | 변경 |
|---|---|
| `Assets/Art/solid_bar.png` | 8 × 8 흰색 이미지를 추가했습니다.<br>`ImageImportSettings` 규칙에 따라 Sprite (Single) 로 들어옵니다. |
| `Assets/Editor/PrefabBuilder.cs` | `SolidBarSprite` 경로를 추가하고 `HPFill` 에 지정합니다. |
| `Assets/Editor/GameSceneBuilder.cs` | `Img_PlayerHpFill` 에 같은 Sprite 를 지정합니다. |
| `Monster_Base.prefab` · `Field_01.unity` · `Field_02.unity` | 전체 재생성 없이 해당 이미지의 `m_Sprite` 1행만 바꿨습니다.<br>Variant 6개는 원본 값을 따르므로 바뀐 파일이 없습니다. |
| `Assets/Tests/EditMode/HpBarSpriteTests.cs` | Filled 이미지에 Sprite 가 비어 있으면 실패하는 검사 3건을 추가했습니다. |

강사용 `build_art.py` 에도 `solid_bar.png` 를 만드는 함수를 넣었습니다.
